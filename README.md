# SWYNEX - Exploratory Data Analysis

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) using the cleaned dataset from Task 1.

The analysis was completed using Microsoft Excel to calculate important statistics, identify trends and patterns, detect possible anomalies, and create charts.

## Dataset

The dataset contains customer and transaction information, including:

- Customer ID
- Name
- Surname
- Gender
- Birthdate
- Transaction Amount
- Date
- Merchant Name
- Category

## Tools Used

- Microsoft Excel
- PivotTables
- Excel formulas
- Charts

## Analysis Performed

The following analyses were performed:

1. Overall transaction statistics
2. Category-wise transaction analysis
3. Gender-wise transaction analysis
4. Monthly transaction trend analysis
5. High-value transaction analysis
6. Anomaly checking

## Key Insights

The analysis helped identify useful patterns and trends in the transaction data.

1. Overall transaction activity was analysed using total, average, minimum, and maximum transaction values.
2. Transaction amounts were compared across different categories.
3. Gender-wise transaction activity was analysed.
4. Monthly transaction trends were examined to understand changes over time.
5. High-value transactions and possible unusual values were analysed.

## Conclusion

The exploratory data analysis provided a better understanding of the cleaned transaction dataset.

Using Excel, I calculated important statistics, created PivotTables and charts, analysed trends and patterns, and identified useful insights from the data.
